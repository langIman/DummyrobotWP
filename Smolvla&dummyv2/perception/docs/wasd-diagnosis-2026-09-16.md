# WASD 输入已收到但没有运动的诊断

实机控制未进行自动运动测试。读取了运行状态和日志，使用独立 ROS_DOMAIN_ID=194
启动不含 USB/HTTP 桥接的 MoveIt 模型回放，与实机 ROS 域分离。

## 证据

- 主控返回的硬件坐标角度：`[0.10, -75.11, 180.44, -0.01, 0.15, 0.09]` 度。
- 对上述姿态持续发送 W 对应的 `linear_x=0.05 m/s`，4 秒内无轨迹输出。
- MoveIt 日志持续报告 `Very close to a singularity, emergency stop`。
- 同时 ServoStatus.code 为 4（碰撞接近减速），单一状态码未反映导致无轨迹的奇异停止。
- 对照模型姿态 `[0, 0, 90, 0, 45, 0]` 在同样输入下产生约 200 次轨迹更新，
  无奇异停止警告。该角度仅用于模型测试，不是验证过的实机安全运动目标。

## 修复

- 网关订阅本 ROS 域的 Servo 警告，将最近 1 秒的奇异停止单独返回；页面同时呈现
  奇异停止和碰撞状态，服务保留暂停原因。
- 控制循环不再在每次查询轨迹后先把输出状态重置为 idle；实际发送时显示 sending_target。
- 已消费过但变旧的轨迹也触发过期暂停，避免一直显示等待新轨迹。
- 网络读取结束后重新检查是否已经退出控制，避免继续使用查询前的使能快照。
- 保留奇异阈值 500、碰撞检查、单次关节变化限制及速度设置。

## 验证

106 项 Python 测试通过；真实 collect.js 在无网络 DOM 模拟中的中文输入法 WASD、
松键、文本输入和失焦测试通过。隔离 ROS 回放复现并验证警告通道。
可使用 `motion/probe_servo_offline.py` 在已加载项目 ROS 环境的 WSL 中重现。

限制：诊断针对主控返回的角度，不等于独立测量了物理姿态；没有验证实机沿对照姿态运动。

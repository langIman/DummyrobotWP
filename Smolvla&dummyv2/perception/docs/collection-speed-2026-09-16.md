# 0.6.1 数据采集控制提速

用户要求同时提高速度、调整过于保守的碰撞减速参数。最终配置：

| 参数 | 原值 | 新值 |
| --- | --- | --- |
| 平移输入速度 | 0.05 m/s | 0.10 m/s |
| 鼠标最大转向速度 | 0.12 rad/s | 0.24 rad/s |
| 流式命令的固件速度参数 | 4 | 8 |
| 自身碰撞预减速距离 | 10 mm | 5 mm |
| 相对反馈的关节目标差上限 | 4° | 8° |

原有模型检查表明，底座与第二段在准备位相距约 8.48 mm，在 2346 组 J1/J2 离线采样中
最小间隙约 6.14 mm。5 mm 的设置消除了这些已验证姿态的额外碰撞减速；这不是
真实装配尺寸的测量，也不是对所有可能姿态无碰撞的证明。

提速后首次隔离测试发现合法目标步长会超过旧 4° 限制，因此将检查配套调整至 8°。
目标仍从反馈计算。流式速度参数 8 是固件命令值，不能标成 8°/秒；实机速度还受
减速比、驱动参数、反馈及发送频率影响。回零、休止和准备位固定速度 4 不变。

## 验证

- 134 项 Python 自动测试通过，覆盖新速度映射、8° 边界、松键、急停、反馈和录制。
- Node 键盘测试通过，覆盖中文输入法、松键、失焦、文本输入和长按准备位。
- 实际 MoveIt + 网关 + 生产控制类 + 假串口在 ROS_DOMAIN_ID=196 中运行：
  W/A/鼠标转向均有响应，松键保持，卡住 3 秒暂停；最大目标差约 5.51°，低于 8°。
  假机械臂速度上限仍为 4°/秒，这是故意保留的慢反馈跟随压力条件，不是实机速度。
- 真实网关 HTTP 入口接受 0.10 m/s、0.24 rad/s，拒绝超过范围的数值。
- 在隔离域加入包围机械臂的模拟障碍，确认碰撞停止状态 code=5 且停止输出。
- 持续 4 秒向静止反馈输入 0.10 m/s，目标差稳定在约 5.09°，没有继续累积；
  折叠姿态仍触发奇异停止。桌面与窄屏浏览器测试通过，页面正确显示 10 cm/s 和 13.8°/s。
- 报告位于 `runtime/control-loop-offline.json`；该脚本没有连接 8765 或访问 USB。
- 服务重启到 0.6.1 后，读取线上 ROS 参数确认自身预减速距离为 5 mm；使用同一
  线上模型离线复算，准备位碰撞速度比例为 1.0（不减速）。报告在
  `runtime/collision-distance-061-report.json`。实际网页以只读浏览器确认显示新速度。

原固件、原 dummy_moveit_ws、碰撞豁免矩阵未修改。没有自动使能或实机运动测试。
